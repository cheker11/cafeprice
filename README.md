# ☕️ НаЧасі Кава — Платформа передзамовлення «До твого приходу» (Україна)

Вебплатформа миттєвого передзамовлення свіжозвареної кави за 3–5 хвилин до приходу в улюблені спешелті кав'ярні України. 

**Головна ідея:** гість замовляє напій на виході з метро чи офісу — бариста змелює свіже зерно та збиває шовковисту мікропінку точно під крок гостя. Людина переступає поріг закладу, забирає свою чашку з персональним стікером та не витрачає жодної секунди в черзі біля каси.

---

## 🌟 Ключові можливості

### 1. Режим клієнта (Гість)
- **Каталог спешелті кав'ярень за містами**:
  - **Київ**: *Yellow Place, Takava Coffee-Buffet, One Love Coffee, Blur Coffee, Idealist Coffee Co*.
  - **Львів**: *Світ Кави, Black Honey, Палярня Чехович*.
  - **Одеса**: *Atelier. Design & Coffee, Foundation Coffee Roasters*.
  - **Дніпро**: *White Coffeebar*.
  - **Харків**: *Pakufuda Coffee*.
- **Таймінг прибуття**:
  - `3 хв` (Біжу від метро / вже на розі)
  - `5 хв` (⭐️ Золотий стандарт спешелті — температура подачі рівно 65°C)
  - `10 хв` (Спокійна піша прогулянка)
  - `15 хв` (Виходжу з офісу чи зустрічі)
- **Кастомізатор напою**:
  - Розмір порції (S, M, L / мл).
  - Альтернативне молоко (*Oatly Barista*, бананове, безлактозне, мигдальне, кокосове).
  - Зерно свіжого обсмажування (Ефіопія Гуджі — ягідна, Колумбія Уїла — шоколадна, Кенія, Декаф).
  - Крафтові сиропи (власна солона карамель, лаванда, мадагаскарська ваніль).
  - **Еко-знижка за своє горнятко**: автоматичне віднімання `-10 ₴` за власний тамблер.
- **Швидка оплата в 1 клік**:
  - Apple Pay, Google Pay, Monobank (monocheckout) та банківські картки онлайн.
- **Живий трекер замовлення (Live Tracker)**:
  - Секундомір зворотного відліку в реальному часі.
  - 4 етапи приготування (Прийнято → Помел → Екстракція → На стійці Pick-up).
  - Електронний талон з персональним номером (наприклад, `#НЧ-284`) та QR-кодом.
  - Кнопка **«🔔 Я вже біля дверей!»** — миттєвий пінг на бар баристі.
  - Кнопка **«⏳ Запізнююсь на +2 хв»** — коригування таймінгу приготування.
- **Інтерактивна схема-мапа пішої ходи**:
  - Радіуси 3 хв, 5 хв та 10 хв пішки від точки гостя.

### 2. Екран кав'ярні (Термінал Баристи)
- Перемикання в один клік у верхньому меню (`Для кав'ярень ↔ Клієнт`).
- Список замовлень, відсортований за таймінгом приходу гостей.
- Спливаюче сповіщення при натисканні гостем «Я біля дверей!».
- Керування статусами: `Прийнято` → `Почати готувати` → `На стійці Pick-up` → `Видано`.

## 🛠 Технологічний стек

- **Фреймворк:** React 19 + TypeScript
- **Збирач:** Vite 8
- **Стилізація:** Tailwind CSS v4 (мобільна адаптивність, чиста типографіка Cabinet Grotesk + Plus Jakarta Sans)
- **Іконки:** Lucide React
- **Архітектура:** Модульна компонентна модель, чистий React Context API для синхронізації між клієнтом і терміналом баристи

## 🚀 Швидкий старт (Локальний запуск)

### Передумови
Встановлений [Node.js](https://nodejs.org/) версії 18+ (рекомендовано 20+).

### 1. Клонування репозиторію
```bash
git clone https://github.com/your-username/nachasi-coffee-ua.git
cd nachasi-coffee-ua
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Запуск у режимі розробки
```bash
npm run dev
```
Відкрийте у браузері: `http://localhost:3000`

### 4. Збірка для продакшену
```bash
npm run build
```
Зібрані оптимізовані файли будуть створені в папці `dist/`.

### 5. Попередній перегляд зібраної версії
```bash
npm run preview
```

## 🌐 Інструкція з публікації (Деплой)

### Варіант 1: GitHub Pages (Через готову папку `/docs` — без білого екрану!) ⭐️

**Чому раніше виникав білий екран:**
Якщо в налаштуваннях GitHub Pages обрати корінь `/(root)`, GitHub віддає сирий `index.html` з посиланням на TypeScript-файл `src/main.tsx`, який браузери не вміють запускати напряму.

**Як запустити зараз (вже скомпільовано):**
1. Завантажте оновлений проєкт на GitHub (у ньому вже створено скомпільовану папку `/docs`).
2. У вашому репозиторії відкрийте вкладку **Settings** (угорі) → **Pages** (у лівому меню).
3. У блоці **Build and deployment**:
   - **Source:** оберіть `Deploy from a branch`
   - **Branch:** оберіть `main` (або `master`)
   - **Folder:** замість `/(root)` оберіть 👉 **/docs**!
4. Натисніть **Save**.
5. Зачекайте 30-60 секунд та оновіть сторінку вашого сайту — він запуститься ідеально!

### Варіант 2: Vercel (1 клік без будь-яких налаштувань)
1. Зайдіть на [vercel.com](https://vercel.com) та натисніть **Add New** → **Project**.
2. Оберіть ваш репозиторій з GitHub.
3. Натисніть **Deploy** — Vercel автоматично збирає проєкт і видає готове посилання.

### Варіант 3: Netlify
1. Перейдіть на [netlify.com](https://netlify.com) → **Add new site** → **Import an existing project**.
2. Оберіть репозиторій з GitHub та натисніть **Deploy site**.

│   ├── context/
